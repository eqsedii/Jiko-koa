# Jikokoa Limited website

Plain HTML/CSS/JS. No build step. Works on GitHub Pages.

## Put it online (from a phone)
1. Unzip this file in your Files app.
2. Open the `jiko-koa` repo on github.com, tap **Add file > Upload files**, select everything inside the unzipped folder (index.html, shop.html, about.html, contact.html, and the css, js, assets folders) and commit.
3. Repo **Settings > Pages > Deploy from a branch > main / (root)**. Your site appears at `https://<username>.github.io/jiko-koa/`.

## Edit
- Prices, products, sizes: `js/products.js`
- WhatsApp / phone / map link: `js/products.js` (bottom, JK_CONFIG)
- Jiko Mama Yao photo: replace `assets/img/jiko-mama-yao.jpg` (currently a copy of the Jikokoa photo)
